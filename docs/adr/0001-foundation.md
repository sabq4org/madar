# ADR0001 — مستودع TypeScript وPostgreSQL واحد

الحالة: معتمد للمرحلة الأولى. التاريخ:2026-11-17.

القرار: Next.js للويب، Fastify للـAPI، عامل Node.js منفصل، PostgreSQL17 وpg-boss، pnpm workspaces. Node26 في التطوير وCI والحاويات؛ كود الخدمات يستهدف Node24.12 فأحدث، لكن تحقق التسليم على26.

البديل الأول كان Redis وطابور مستقل؛ يضيف خدمة ونسخًا احتياطيًا ومراقبة دون حاجة مثبتة في تجربة المصادر المحدودة. البديل الثاني تشغيل الجمع داخل طلب الويب؛ يربط وقت استجابة المستخدم بأعطال المصادر ولا يلائم المهام المستمرة.

المفاضلة: تخزين البيانات والطابور على قاعدة واحدة يقلل التشغيل، ويجمع حملهما ونقطة فشلهما. عند زيادة الحمل نفصل العمليات/الموارد وفق القياس. عامل دائم مطلوب؛ وظيفة serverless قصيرة العمر وحدها ليست بديلًا مباشرًا.

لا اختيار لمزود سحابة ولا إنشاء موارد مدفوعة في هذا القرار. الحاوية الحالية تضم أدوات التطوير والترحيل لتبسيط أول تسليم؛ تقليل صورة الإنتاج وفصل صلاحيات الترحيلات مطلب قبل الإطلاق.
