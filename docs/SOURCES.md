# إدخال المصادر وسياسة المحتوى

هذا سجل تشغيل وتقنية، وليس حكمًا قانونيًا على حقوق كل ناشر. وجود RSS أو سماح `robots.txt` لا يعني الإذن بإعادة نشر المحتوى. يسجل مشغل مدار أساس الاستخدام الذي راجعه قبل تفعيل المصدر.

## القنوات

| القناة            | وضع المرحلة الأولى                      | متطلبات لاحقة                                              |
| ----------------- | -------------------------------------- | --------------------------------------------------------- |
| RSS/Atom          | موصل منفذ؛ الاتصال الشبكي معطل افتراضيًا | عنوان HTTPS مباشر، نطاق مسموح، وأساس حقوق موثق            |
| XML تجريبي        | منفذ محليًا؛ ممنوع في الإنتاج            | لا يمثل ناشرًا أو خبرًا حقيقيًا                               |
| API ناشر أو وكالة | غير منفذ                               | اتفاق وصلاحيات وحدود استخدام                               |
| Webhook من ناشر   | غير منفذ                               | توقيع ومفاتيح وتدوير ومنع إعادة الطلب                     |
| زاحف صفحات        | غير منفذ                               | حقوق وشروط وrobots وتحديد معدل وآلية استخراج خاصة بالمصدر |
| X والمنصات        | غير منفذ                               | قناة وصول معتمدة وشروط API والعرض والحذف وميزانية مستقلة  |

## إدخال المصدر

1. احفظ اسم الناشر ورابطه والعنوان النهائي للتغذية، وحدد النطاقات الصريحة المسموح بجلبها.
2. ابدأ بالقيمتين `rightsStatus=pending` و`enabled=false`. سجّل المرجع أو الاتفاق في `rightsBasis` دون أسرار.
3. اختر `metadata_only` للعناوين والروابط والأوقات فقط، أو `excerpt` لمقتطف مسموح لا يتجاوز 600 حرف. لا تخزن الصور أو المقال كاملًا.
4. بعد اعتماد الاستخدام، غيّر الحقوق إلى `approved` ثم فعّل المصدر. هذه حالة إذن استخدام داخلية، وليست شارة تحقق من صحة الخبر.
5. فعّل `ENABLE_NETWORK_INGESTION=true` في البيئة المقصودة، ثم أعد تشغيل API والعامل. ابدأ بمصدر واحد وراجع النتائج.

جسم إنشاء المصدر، ويُرسل إلى `POST /v1/admin/sources` بمفتاح Bearer من الخادم:

```json
{
  "name": "اسم الناشر",
  "homepageUrl": "https://news.example.com",
  "feedUrl": "https://news.example.com/rss.xml",
  "allowedHosts": ["news.example.com"],
  "enabled": false,
  "rightsStatus": "pending",
  "contentPolicy": "metadata_only",
  "pollIntervalSeconds": 300
}
```

العناوين أمثلة وليست مصادر موصولة. لا تضع مفتاح الإدارة في JavaScript المتصفح. يغيّر `PATCH /v1/admin/sources/{id}` القيم `enabled` و`rightsStatus` و`rightsBasis` و`contentPolicy` فقط؛ ويتطلب تغيير عنوان التغذية إدخالًا جديدًا في هذه المرحلة.

## الإيقاف والسحب

- `enabled=false`: يوقف الجمع؛ وتبقى المواد السابقة المعتمدة قابلة للعرض.
- `rightsStatus=blocked`: يوقف الجمع ويخفي المواد فور الطلب التالي من API.
- `contentPolicy=metadata_only`: يحجب مقتطفات المواد ونسخها في API، ولا يمحو الأرشيف الداخلي تلقائيًا.
- للإيقاف الطارئ الشامل، اضبط `ENABLE_NETWORK_INGESTION=false` وأعد تشغيل العامل وAPI. قد تنتهي الطلبات الجارية قبل الإيقاف؛ ويمكن أيضًا حجب المصدر لمنع عرضه.

تتطلب حقوق الصور والعلامات والترجمة والتلخيص والحذف اتفاقًا مستقلًا بحسب المصدر والاستخدام. لا تعوض التقنية غياب الإذن.

## حدود السرعة والجودة

لا يضمن الاستطلاع الحالي وصولًا فوريًا؛ فالوقت يتأثر بفاصل المصدر وانتظار الجدولة ومدة الجلب وإعادة المحاولة. الأولوية لاحقًا لقناة دفع مباشرة من الناشر عند توفرها. وقت النشر منقول وقد يكون خاطئًا، لذلك يحتفظ النظام بوقت الرصد مستقلًا. تعديل العنوان قد ينشئ نسخة جديدة، ولا يعني تغير حقائق الخبر.
