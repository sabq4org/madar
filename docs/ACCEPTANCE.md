# قبول المرحلة الأولى

تاريخ التحقق المحلي: 2026-11-17. البيئة: macOS، Node 26.12.1، pnpm 11.25.0، PostgreSQL 17.10 في عنقود خاص بالمشروع. المرجع المستمر لفحوص كل commit هو [GitHub Actions](https://github.com/sabq4org/madar/actions/workflows/ci.yml).

## الأدلة المنفذة

| الاختبار                                | النتيجة                                                                                                               |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `pnpm install --frozen-lockfile`       | نجح، مع تصريح build scripts محدد في pnpm                                                                              |
| `pnpm lint`                            | نجح باستخدام إعداد Biome recommended                                                                                  |
| `pnpm typecheck`                       | نجح للحزم والتطبيقات والاختبارات والسكربتات                                                                            |
| `pnpm test`                            | 8 اختبارات وحدة نجحت؛ تشمل RSS/Atom/XML declaration والكيانات والروابط وDNS والمهل وحجم الرد والإلغاء و304 ومنع الشبكة |
| `pnpm test:integration`                | 11 اختبارًا نجحت على قاعدة PostgreSQL مؤقتة مستقلة وحُذفت بعد انتهاء الاختبار                                            |
| `pnpm build`                           | نجح بناء API والعامل وصفحات Next.js، وتجهيز standalone والملفات الثابتة                                               |
| `node scripts/smoke.mjs`               | نجح على الخدمات المبنية: الطابور ← قاعدة البيانات ← API ← صفحة الويب، مع نسخ المادة والخط والنموذج البصري             |
| `pnpm audit --prod --audit-level=high` | لم تُبلغ الأداة عن ثغرات معروفة وقت الفحص؛ لا يمثل ضمانًا بعد تحديث التبعيات                                              |
| فحص المتصفح                            | رُصدت المواد التجريبية وصفحة التفاصيل وسجل النسخ وصفحة المصادر؛ لم تظهر أخطاء JavaScript في السجل الذي فُحص             |

تغطي اختبارات التكامل إعادة الترحيلات، الجاهزية، منع التكرار بما فيه الجمع المتزامن، حفظ تغير A→B→A، المؤشر عند تساوي الأوقات، مصادقة الإدارة ومدخلاتها، حجب المصدر المسحوب، منع البيانات التجريبية في الإنتاج، تطبيق تغيير سياسة المقتطف أثناء الجلب، استهلاك الطابور، ونقل مهمة فاشلة إلى طابور الفشل.

## مراجعة مستقلة وإصلاحات

فُصل تنفيذ موصل الجمع والواجهة عن مراجعة المنسق، ونُفذت مراجعة مستقلة للخدمات. أُصلح فحص الجاهزية ليشمل جميع الترحيلات المطلوبة، وأعيد تطبيق سياسة المقتطف داخل معاملة الحفظ بعد قفل المصدر. أضيفت اختبارات تمنع رجوع العيبين. كما أُصلحت معالجة304 واختيار جذر XML وإلغاء الردود المرفوضة بدل استهلاكها بلا حدود.

## الحدود المعلنة

- لم يُشغّل Docker على الجهاز المحلي لأنه غير مثبت. مهمة CI مستقلة تبني الصورة وتشغّل Compose وتزرع المصدر التجريبي وتنفذ smoke؛ حالة تشغيلها الفعلية ظاهرة في رابط Actions، ولا تُستنتج من وجود الملف فقط.
- لم تُربط مصادر إخبارية حقيقية ولم يُجرَ زحف خارجي. الاختبارات الشبكية تستخدم نقلًا وDNS محاكيين؛ مسار الطابور والتخزين والعرض يعمل على بيانات تجريبية فعلية داخل القاعدة.
- لم تُنشأ موارد سحابية أو تُنشر خدمة عامة. لا مصادقة مستخدمين أو تنبيهات أو ذكاء اصطناعي أو تطبيق متجر.
- لم يُختبر استرجاع نسخة احتياطية أو تحمل حمل إنتاجي. خطة التشغيل توثق المتطلبات قبل الإطلاق.
- فحص العرض في المتصفح كان مكتبيًا. توجد قواعد CSS للجوال، لكن محاولة ضبط viewport بالأداة لم تغير أبعاده؛ لا ندعي اختبار جهاز جوال فعلي.

نتيجة المرحلة: أساس محلي قابل للتشغيل والاختبار والتطوير اللاحق، مع فصل واضح بين المنتج التجريبي وميزات مدار التحريرية المستهدفة.
