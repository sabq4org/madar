# مدار

أساس منصة عربية لمتابعة الأخبار وتطور القصص، مع حفظ المصدر والتعديلات وتقليل التكرار. **هذه المرحلة أساس تقني محلي؛ ليست النسخة التجارية من التطبيق.**

## الموجود الآن

- واجهة عربية RTL تعرض مواد قاعدة البيانات ومصادرها ونسخ تعديلاتها.
- API للقراءة، وإدارة المصادر بمفتاح سري، وفحوص صحة وجاهزية.
- عامل جمع RSS/Atom وبيانات تجريبية، مع طابور PostgreSQL دائم وإعادة محاولة ومهام فاشلة منفصلة.
- حفظ المقال مرة واحدة لكل رابط ومصدر، وتسجيل نسخة جديدة عند تغير العنوان أو المقتطف المسموح.
- PostgreSQL وترحيلات وبذر تجريبي، Docker Compose، GitHub Actions، اختبارات وتوثيق.

حسابات المستخدمين، ربط القصص دلاليًا، «ما تغيّر» على مستوى الحقائق، الإشعارات، موصل X والزواحف وتطبيقات المتاجر لم تنفذ بعد. النموذج البصري السابق متاح في `/prototype.html`، ويستخدم بيانات افتراضية مستقلة عن التطبيق.

نموذج الويب الجديد متاح في `/design`: بحث وتصفية وحفظ ومتابعة وملخص يوم وملف قصة تفاعلي، مع بيانات ومصادر افتراضية معلنة. الحفظ والمتابعة في ذاكرة الصفحة فقط؛ تفاصيل التصميم في [WEB-DESIGN.md](docs/WEB-DESIGN.md). إعداد الخدمات التي أنشأها المستخدم على Railway موثق في [RAILWAY.md](docs/RAILWAY.md)، مع إبقاء جمع المصادر الحقيقية معطلًا وقت التحقق المسجل.

## تشغيل سريع

المتطلبات: Node.js 26، pnpm 11.25.0، وPostgreSQL 17 أو Docker Compose. استخدم الإصدارات المقفلة في `pnpm-lock.yaml`.

```sh
git clone https://github.com/sabq4org/madar.git
cd madar
pnpm install --frozen-lockfile
pnpm env:init
docker compose up -d postgres
pnpm db:migrate
pnpm db:seed
pnpm dev
```

بديل Docker عند توفر أدوات PostgreSQL محليًا: `pnpm db:local:start` ينشئ عنقودًا خاصًا بالمشروع داخل `.local/` على `127.0.0.1:55432`، ويُوقف بـ`pnpm db:local:stop`. لا تستخدم الطريقتين معًا على المنفذ نفسه. لا يعدّل السكربت قاعدة PostgreSQL القائمة على الجهاز.

الويب: <http://127.0.0.1:3100>. API: <http://127.0.0.1:4100/health/ready>.

العامل يجمع المصدر التجريبي تلقائيًا بعد تشغيله؛ ويمكن حجز مهمة إضافية بـ`pnpm demo:collect`. الأخبار افتراضية وموسومة. `pnpm env:init` ينشئ مفتاح إدارة عشوائيًا داخل `.env` المحجوب عن Git ولا يطبع المفتاح.

```sh
pnpm check
pnpm test:integration
```

فحص التكامل ينشئ قاعدة مؤقتة باسم `madar_test_*` على PostgreSQL المحلي ويحذفها بعد الفحص، ويحتاج مستخدمًا لديه صلاحية إنشاء قواعد. لا يفرغ قاعدة التطوير.
