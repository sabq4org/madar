# تصور واجهة الويب — مدار

تاريخ: 2026-11-17. كان الطلب الأول تصميم الويب كنموذج تفاعلي محلي قابل للمراجعة. المسار `/design` مستقل عن واجهة البيانات الفعلية. بعد المعاينة طلب المستخدم رفع العمل ودمجه؛ يتضمن الدمج إتاحة مسار النموذج في بناء الإنتاج المتصل بالمستودع، دون تغيير API أو تفعيل مصادر.

## الفكرة

واجهة متابعة للأحداث: عنوان رئيسي بصري، آخر تطور داخل كل ملف، ثم المصادر والتسلسل الزمني. القيمة المعروضة للمستخدم هي معرفة ما تغير والرجوع إلى أصل المعلومة. المتابعة والحفظ والبحث في هذه النسخة محاكاة محلية فقط. شريط ثابت واضح يعرّف المحتوى بأنه افتراضي، وجميع الإسنادات داخل التفاصيل مصادر توضيحية وليست أخبارًا موثقة.

## نظام التصميم

- خلفية ضبابية فاتحة `#F3F6F8`، أسطح بيضاء `#FFFFFF`، حبر كحلي `#182E40`، أخضر بترولي `#087F83` للتفاعل، رمادي نصي `#667783`، وكهرماني `#AD610A` للتطور الجديد فقط.
- IBM Plex Sans Arabic المحلي لجميع النصوص؛ عناوين 38/28/21، متن 15–17، معلومات مساندة 12–13. محاذاة يمين، وسطور مريحة للقراءة. الأرقام لاتينية داخل النموذج.
- تخطيط مكتبي واسع بحد أقصى 1500px: تنقل يمين، مساحة أخبار رئيسية مرنة، ملخص ومتابعات على اليسار. رأس علوي يجمع الهوية والبحث. عند تضييق الشاشة يتحول التنقل لشريط مضغوط ويتدفق المحتوى في عمود واحد.

```text
┌────────── هوية مدار / بحث في القصص / أدوات العرض ──────────┐
│ ملخص ومتابعات │ عنوان اليوم وفلاتر الاهتمامات │ تنقل      │
│               │ قصة رئيسية بالصورة + ما تغير   │ يومك      │
│ ملفات         │ قصص ثانوية بمقاسات مناسبة     │ تتابع     │
│ تنتظر تطورًا  │ آخر التطورات                   │ محفوظات   │
└───────────────────────────────────────────────────────────┘
```

الاختيار المميز الوحيد هو «ملف القصة»: صورة كبيرة وعنوان، ثم شريط تطور موجز يفتح سياقًا زمنيًا ومصادر توضيحية. باقي العناصر هادئة، بلا أرقام نمو تجميلية أو رسوم لوحة تحكم. لا شبكة صناديق متماثلة؛ تختلف مساحة المادة الرئيسية عن المواد المساندة والملخص.

## مراجعة الاتجاه قبل التنفيذ

واجهة أخبار تقليدية ذات عناوين متكررة لا تحقق فكرة مدار. لذلك تحوّل التركيز إلى ما تغيّر داخل الملف وإمكانية متابعة الموضوع. وتُستبعد المقاييس الوهمية وشارات «موثوق» أو «تحققنا»؛ عدد المصادر التوضيحي لا يمثل عدد تأكيدات مستقلة. تفاصيل القصة تميز بين المعلومة الجديدة وما لا يزال غير معروف.

## القبول

- رئيسية ويب متجاوبة مع فتح تفاصيل القصة وتبديل تبويبات التطورات والمصادر.
- بحث وفلاتر وحفظ ومتابعة تعمل داخل النموذج، مع حالات فراغ مفهومة.
- لوحة ملخص تفتح محتوى فعليًا في النموذج؛ لا أزرار شكلية توحي بوظائف مكتملة.
- دعم لوحة المفاتيح، تركيز مرئي، إغلاق التفاصيل بـEscape، واحترام reduced motion.
- لا اتصالات API أو أسرار أو إشعارات حقيقية. صور وخطوط محلية مع توثيق مصدر الصور.
- فحص فعلي في المتصفح المكتبي والجوال، مع فحص الأنواع والبناء ومراجعة مستقلة.

## نتيجة التنفيذ والتحقق

نُفذ النموذج في `/design` بثلاثة أعمدة على الكمبيوتر، وصورة رئيسية بجوار النص، وبطاقتين مصورتين تليهما قصص نصية مضغوطة. تفاصيل الملف تعرض «ما كنا نعرفه / ما تغيّر / ما ننتظره» مع السياق والمصادر التوضيحية. الصور مرخصة ومحفوظة محليًا؛ الإسناد في `apps/web/public/design-assets/CREDITS.md`.

نجح فحص Biome وبناء Next.js مع TypeScript وتجهيز standalone. فُحصت النسخة المبنية على `http://127.0.0.1:3101/design`: البحث والفلاتر وحالة عدم وجود نتائج، والحفظ والمتابعة والملخص وتفاصيل القصة، وإغلاق الحوارات واستعادة التركيز. فُحص العرض المكتبي ومحاكاة عرضَي 360 و390px دون تمدد أفقي للصفحة؛ ليس اختبار جهاز جوال فعليًا. أكدت مراجعة مستقلة اتساق المتابعة بحسب التصنيف وأزرار تبديل محتوى التفاصيل.

الحفظ والمتابعة في ذاكرة الصفحة فقط؛ إعادة تحميل الصفحة تعيد الحالة الابتدائية. النموذج لا يجلب أخبارًا ولا يستدعي API، وكان محليًا عند المعاينة الأولى. بناء الإنتاج يشمل `/design` بعد رفعه ودمجه بطلب المستخدم؛ المسار موسوم كتجريبي ببيانات افتراضية مع `noindex`، ولا تعني إتاحته اعتماد التصميم النهائي أو إطلاق منتج الأخبار. صور المعاينة المحلية محفوظة في مجلد مخرجات المحادثة `outputs/madar-web-design/`.
