# واجهة مدار — خطة التصميم والتنفيذ

## الاتجاه

واجهة تحريرية هادئة لخدمة عربية تقرأ مواد منشورة من مصادرها. العنصر المميز هو عنوان عربي واضح ومساحة واسعة للقراءة؛ لا مؤشرات نشاط ولا وعود تحقق. تبقى روابط النموذج التفاعلي السابق منفصلة وموسومة كمرجع.

## الرموز

- الألوان: أبيض `#fff` للصفحة، كحلي `#172b46` للنص، أزرق `#245be8` للتفاعل، أخضر مزرق `#127768` لحالة المصدر، ورمادي أزرق فاتح `#eef2f7` للفواصل والخلفيات الثانوية.
- الخط: IBM Plex Sans Arabic محليًا، من ملف النموذج مع الترخيص المرفق؛ لا طلب خط خارجي وقت البناء.
- التخطيط: اتجاه RTL، عمود قراءة رئيسي محدود العرض، شريط علوي خفيف، صفوف مواد تفصلها قواعد دقيقة، وتذييل تنقل بسيط. التفاصيل تعرض المادة ثم سجل النسخ ومصدرها.

```text
┌ مدار ───────── آخر المواد | المصادر ─┐
│ مواد منشورة من مصادرها              │
│ ─────────────────────────────────── │
│ العنوان                              │
│ المصدر    تاريخ النشر     تجريبي؟    │
│ المقتطف                               │
└──────────────────────────────────────┘
```

الصفحات محاذاة لليمين ولا تستخدم أعمدة صحفية متعددة. على الهاتف تتحول المساحة إلى هامش صغير دون إخفاء بيانات المصدر. حالات الفراغ وتعطل API نصوص مباشرة؛ لا بيانات شكلية تحاكي تشغيلًا حقيقيًا.

## التنفيذ

تطبيق Next.js App Router يقرأ API من الخادم فقط عبر `API_INTERNAL_URL` (الافتراضي `http://127.0.0.1:4100`). كل طلب `no-store` ومهلة 3 ثوانٍ. يستخدم DTOs من `@madar/contracts`، مع صفحات `/` و`/articles/[id]` و`/sources`. لا توجد مصادقة أو إدارة أو متابعة مستخدم.

ملف `public/prototype.html` مرجع التصميم التفاعلي السابق؛ ليس مصدر بيانات للتطبيق. أي مادة تجريبية تُوسم «تجريبي»، ولا تعني مراجعة الخبر أو التحقق منه.
