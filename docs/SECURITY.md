# أمن المرحلة الأولى

## ما نُفّذ

- لا يبدأ جمع المصادر إلا بعد اجتياز بوابة الاعتماد وبوابة التشغيل الشبكي، وهي معطلة افتراضيًا.
- يقتصر جلب RSS على HTTPS، ولا يقبل بيانات دخول داخل الرابط أو منافذ مخصصة أو تحويلات. يجب أن تشير عناوين DNS إلى شبكات عامة، ويُثبّت عنوان الاتصال مع التحقق من شهادة اسم المضيف.
- مهلة الجلب 8 ثوانٍ، والحجم الأقصى 1 ميغابايت. تُرفض تعليمات DTD وENTITY، ويُعامل المحتوى كنص عادي لا HTML. يعرض React النصوص بصيغة آمنة.
- تتطلب إدارة المصادر مفتاح Bearer، وتُقارن قيمته مقارنة ثابتة الزمن. حد حجم الطلب 16 كيلوبايت، وحد الطلبات 120 في الدقيقة لكل نسخة API. لا توجد سياسة CORS عامة، ولا يوضع المفتاح في المتصفح.
- تستخدم استعلامات SQL معاملات وتتحقق من المدخلات، ويُقفل المصدر قبل حفظ المواد. لا يعرض مسار القراءة مواد من مصادر غير معتمدة أو مقتطفات لا تسمح بها سياسة المحتوى.
- تُحظر المصادر التجريبية في الإنتاج، ولا تعرض DTOs العامة عنوان التغذية أو تفاصيل أساس الحقوق. رموز الأخطاء في السجلات محدودة.
- ملفات `.env` والقاعدة المحلية والنسخ الاحتياطية مستثناة من Git. تعمل الحاوية بمستخدم غير root، وتُقفل إصدارات التبعيات وتُفحص في CI.

## ما لم يُنفّذ بعد

يوجد مفتاح إدارة واحد للمشغلين؛ وهو لا يمثل هوية مستخدم أو صلاحيات RBAC. لم يُنفّذ بعد MFA أو سجل تدقيق لكل محرر. يجب إبقاء API الإداري خلف شبكة خاصة أو بوابة وصول إلى حين استكمال ذلك. حد الطلبات محلي لكل نسخة، ويحتاج إلى بوابة مشتركة عند التوسع.

لم تُضبط سحابة أو WAF أو PITR أو Sentry أو تنبيهات تشغيل خارجية. لا يُخزّن النص الخام أو الصور. تبقى المقتطفات القديمة مخزنة بعد حجبها إلى أن يُنفّذ إجراء للمحو. يجب تحديد مدد الاحتفاظ والنسخ الاحتياطي والإزالة قبل الإطلاق.

يفصل عقد موصل الجمع بيانات المصدر عن التعليمات. لا يوجد LLM في المسار الحالي. وأي إضافة مستقبلية له تتطلب التعامل مع النصوص باعتبارها محتوى مصدرًا غير موثوق، ومنع وصوله إلى الأسرار أو تنفيذ الأدوات.

## فحوص مطلوبة قبل نشر عام

تشمل الفحوص مراجعة حقوق أول خمسة مصادر، وفصل البيئات وحسابات قاعدة البيانات، وتحسين حجب المخارج إلى الشبكات الخاصة على مستوى البنية، وتدقيق هويات الإدارة، واختبار الاستعادة، واختبار فشل الشبكة وزحام معدل الجمع المتفق عليه. بناء الحاوية وحده لا يثبت تحقق هذه الشروط.
